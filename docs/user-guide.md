# 鋼筋專案計算模擬

使用說明書｜2026-11-03｜Windows 桌面版

本說明書使用模擬案例，不含真實專案、公司內部資料或圖面。軟體用於材料與儲存空間的情境分析，施工期間採日數比例分攤，結果並非即時庫存。

## 1. 第一次使用：完整流程

1. 雙擊「鋼筋專案計算模擬.exe」。
2. 在「成品需求」貼上 Excel 的四欄資料，核對目前列數。
3. 設定可採購原料長度、裁切耗損與餘料保留門檻。
4. 按「計算進料與裁切方案」，在「方案數據」選取可行方案。
5. 檢視「結果與切法」及「圖表比較」。
6. 按「儲存為配置」保存比較用資料；按「儲存為專案」加入專案代號及施工日期。
7. 到「跨專案彙總」勾選專案，設定查詢期間、原料長度級距與餘料模式。
8. 按「彙總勾選專案」，查看各月材料量、儲位與占地。

單一專案只分析材料與裁切；儲位及占地在跨專案彙總時才計算，也可只勾選一個專案進行期間分析。

## 2. 輸入成品需求

在 Excel 選取下列順序的四欄，複製後按「貼上 Excel（取代）」或在需求表按 Ctrl+V。

| 號數 | 長度mm | 數量 | 型式 |
| --- | --- | --- | --- |
| #10 | 5900 | 20 | 1 |
| #10 | 6200 | 10 | 3 |
| #11 | 6000 | 12 | 49 |

長度單位固定為 mm，支數填正整數。可包含欄名與合法千分位；型式請依「型式對照」填寫。號數如 #10、#11、F#11；#11 與 F#11 雖直徑相同，材料身分仍分開。

貼上會取代目前表格，請先保存需要保留的資料。軟體不設固定貼上列數上限；貼上後核對狀態列「已貼上幾列」與表格旁「目前幾列」。Excel 若隱藏或篩選部分資料，請自行確認實際複製的內容完整。

可用「新增列」、「刪除所選列」調整資料；雙擊儲存格編輯。相同需求規格在計算時會合併數量，不會因此漏掉需求。

## 3. 可採購原料長度

| 輸入模式 | 設定方式 |
| --- | --- |
| 指定可採購長度 | 例如 9,10,12；可填 15.2 等小數長度，單位 m |
| 依長度範圍比較 | 例如最短 6.5m、最長 12m、間隔 50cm |

指定清單代表求解時可選用的原料長度，不代表每一種都必須購買。系統會比較單一長度及多種長度搭配的方案，實際支數請看進料組合。

原料長度與成品下料長度不同：前者是購入的整支材料；後者是需求表內實際要切出的尺寸。

## 4. 重要變數與單位

| 變數 | 意義與操作提示 |
| --- | --- |
| 每刀耗損 cm | 每次裁切消耗的長度；允許 0，依實際加工情境設定 |
| 可利用餘料最短 cm | 餘料低於此值算廢料；達到此值才保留 |
| 每方案求解上限 秒 | 各方案的搜尋時間上限；增加時間可能改善結果，無法保證一定證明最佳 |
| 重量上限 噸 | 0 表示不限；正值會限制採購總重量 |
| 架寬 cm／可堆高 cm／架長 m | 用於跨專案估算每格容量及面積 |
| 容積使用率 % | 每格理論容量的折減係數，依經驗設定；須大於 0 且不超過 100 |
| 鋼材密度 kg/m³ | 由鋼筋幾何體積換算重量 |
| 餘料分組級距 cm | 餘料的長度分類；0 代表依實際長度分類 |
| 成品暫存預留 格 | 全場共用成品暫存區的格數，可設 0 |
| 成品暫存 天 | 估算最近幾天尚未領走的成品，可在跨專案頁調整 |

架體參數保存在配置中，單專案裁切方案不以儲位作為比較目標。跨專案合併時，架尺寸、密度、容積使用率、餘料級距與預留格數須一致。

## 5. 裁切與餘料的示意案例

假設需求為同號數 5.9m × 20 支，可購原料 12m，每刀耗損 0cm，可利用餘料最短 50cm。

一組可行切法為每支原料切 5.9m × 2 支，剩 0.2m。共用 10 支原料，原料總長 120m、成品總長 118m、短餘料廢料共 2m。每支的 20cm 餘料低於 50cm，因此列為耗損。

此例僅說明長度平衡，不代表其他需求或加工條件下的最佳方案。軟體不會為了把餘料切短而額外製造沒有需求的成品。

公頭或母頭任一出現時，整支歸為委外完成品；只有 T 頭或無公母頭的既定型式屬廠內加工。委外完成品不加入廠內裁切耗損。型式對照以軟體清單為準。

## 6. 如何閱讀方案結果

「結果與切法」顯示採購組合、每支原料切出的尺寸與支數，以及切後餘長。「方案數據」用相同欄位比較各種策略，先選取方案再保存。

不同方案名稱代表不同目標，例如採購量與耗損優先、原料長度種類少、裁切刀數少、裁後種類少；方案編號不是優劣排名。

「可行，未證明最佳」表示已有滿足需求的方案，但仍可能存在更好的組合。「未取得方案」不一定代表無解，請查看下方完整原因。延長求解時間可能有所改善，不保證在特定秒數內證明最佳。

環形圖顯示成品、保留餘料與耗損占採購重量的比例。直條圖與 XY 圖協助比較耗損與採購量；需求不同的配置不可單憑圖形大小直接評定優劣。

## 7. 儲存配置與建立專案

「配置」保存計算當下的需求、參數與選定切法；「專案」則在配置上加入代號、名稱及施工起訖日期。

建立方式有兩種：選取方案後按「儲存為專案」，或在「跨專案彙總」按「從已儲存配置建立專案」，選取既有配置並帶入。

日期一律輸入 YYYYMMDD，例如 20260101。請特別核對年份：26261130 是西元 2626 年，並非 2026 年。超過 10 年的查詢期間會要求確認。

修改尚未重算的輸入格，不會自動改寫已保存的結果。需要新的結果時，先重新計算並另存。表格支持的名稱與日期欄位可雙擊修改，Enter 儲存、Esc 取消；重新雙擊可切換編輯目標。

## 8. 跨專案儲位：原料長度級距

在「跨專案彙總」勾選要分析的專案；同一專案僅勾選一個版本。可按「使用勾選專案完整期間」帶入日期，再設定每月、每季或自訂期間。

| 級距設定 | 原料分類方式 |
| --- | --- |
| 0m | 同號數＋實際長度各自一類；#10／6m 與 #10／6.1m 分開 |
| 1.5m | 從 0m 起算區間；例如 6m 到未滿 7.5m 為一組 |
| 1m、2m或其他正值 | 依指定級距分組，長度須精確到整數 mm |

不同號數原料分開放。相同號數且落在同一分類的材料，可跨專案共用儲位。級距 0 時，不同專案的 #10／6m 仍可以合放。

正級距採含下限、不含上限：7.5m 屬於 7.5m 到未滿 9m，並不屬於 6m 到未滿 7.5m。這個設定只更動存放分類，不改變已保存的裁切結果。

## 9. 當期餘料與累積保留餘料

「當期新增餘料」是期間內估計新產生的量；「累積保留餘料」是所選專案自開始日起，到該期末已產生且假設仍保留的總量。

例如 1 月新增 2 噸、2 月新增 3 噸、3 月新增 1 噸，累積依序為 2、5、6 噸。合計列顯示期末 6 噸，不把 2＋5＋6 再加一次。

只查詢 7 到 12 月時，仍會帶入所選專案在 7 月以前的估計餘料。專案結束後，累積餘料仍保留；未選取專案的餘料不會自動加入。

餘料儲存模式預設「累積保留（未扣領用）」：以各月期末累積餘料明細重新分組、計算儲位，不直接累加各月格數。若只想比較當期產出空間，可切換「當期產出」後重新彙總。

目前沒有領用、清除或實際回收扣帳，因此累積量是假設全部保留的估算量，並非經盤點的庫存；尚未執行跨專案餘料重新配切。

## 10. 儲位圖與灰色區塊

全場儲位依材料分類、容量計算後，各組向上取整。各專案色塊表示材料占用容量等值，灰色「共用未使用容量」代表已配置格位內尚未填滿的空間。

例如專案 A 占 0.8 格容量、B 占 0.5 格，合計 1.3 格，仍需配置 2 格；其中 0.7 格容量顯示為灰色。灰色不代表額外增加的空儲位，也可能包含成品暫存預留區未使用的部分。

不同號數、不同長度分類的空間未必能互相挪用，因此灰色容量大不等於可以直接減少相同數量的格位。雙擊期間列，或點圖中的柱狀色塊，可查看專案貢獻與存放明細。

容積使用率是事先設定的保守係數；實際格位填充率是材料重量占已配置格位可用容量的比例，兩者意義不同。

每格占地以架寬與架長估算，超長料按延伸長度估算；未包含走道、吊運、支撐或結構承重校核。季度及自訂期間的儲位取月段高峰，不把每月格數相加。

## 11. 常見問題與資料管理

資料很多時，彙總在背景執行，進度列顯示階段與已用時間。計算中變更條件，會要求重新彙總，避免使用舊結果。首次讀取大檔仍可能花時間。

若儲位看起來偏大，先核對原料級距、號數分類、累積餘料模式、架體容量、成品預留格數與暫存天數。若無結果，核對專案勾選、日期、來源明細與參數一致性。

刪除已儲存配置或專案時，先選取正確項目並確認；軟體會保留既有設計的復原副本。刪除專案不代表同時刪除來源配置。

單檔桌面版資料保存在目前 Windows 使用者的本機應用程式資料夾 RebarStorageCalculator 中。更換執行檔名稱不會更動該資料位置。分享 EXE 不會自動同步各人的專案資料，也不等於多人共用資料庫。

備份時請先關閉軟體，再複製整個資料資料夾到受控位置。公開作品集與說明書只使用模擬資料；請勿上傳真實圖面、需求清單或內部專案資料到公開儲存庫。
